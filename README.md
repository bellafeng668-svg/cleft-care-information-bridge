# Cleft Care Information Bridge — Final Starter Dataset

- `index.html` — self-contained public-facing website.
- `dataset.html` — searchable dataset browser.
- `cleft_care_resources_FINAL.csv` — CSV dataset.
- `cleft_care_resources_FINAL.xlsx` — spreadsheet dataset.
- `data.json` — structured JSON.

The dataset contains 17 verified starter records. It is not an exhaustive national directory. National guidance, hospital resources, charitable programs, and local/historical policy examples are explicitly separated.

Research frame: information friction — Findability, Completeness, Trustability, and Actionability.

`last_verified` means the source was checked during this dataset build. It does not mean the underlying policy was issued on that date.
